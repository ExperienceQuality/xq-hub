# Prototypes are local-only under `.prototype/`

A Prototype answers one design question and must not become shipped product or Hub history. We keep Prototype code under `.prototype/`, gitignored, on the local machine only. The lasting output is notes written back into the Idea or Spec. We rejected prototyping in Satellites by default (debris, confuses throwaway with ship) and a dedicated prototypes Satellite (extra repo for disposable work).
