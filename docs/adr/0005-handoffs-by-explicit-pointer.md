# Handoffs are briefs discovered by explicit pointer

Session jumps (grill → prototype → back, or parent → child agent) need a short bridge without becoming a second work queue. A Handoff is Hub markdown under `docs/handoffs/`; the next agent is given its path or linked Ticket at launch. Ready work remains Hub Tickets. We rejected an open-handoff inbox (races and stale briefs under parallel fan-out) and folding every session bridge into a Ticket (too heavy for prototype detours and interrupted grilling).
