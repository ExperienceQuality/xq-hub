# Spec: xq-terminal-registry

**Status:** Active — code-level plan for Satellite `xq-terminal-registry`.

**Related:** [`xq-terminal.md`](xq-terminal.md) · [`xq-terminal-sdk.md`](xq-terminal-sdk.md) · [`xq-terminal-spec-wheel.md`](xq-terminal-spec-wheel.md)

**Ticket:** [#25](https://github.com/ExperienceQuality/xq-hub/issues/25)

## Problem

Specs must be installable to Terminal without Terminal listing each Spec as a dependency, and without unsanitized deps entering the shared env.

## Solution

Meta-package **`xq-terminal-registry`**: human **`specs.yaml`** → **sanitize** → **generate** `pyproject.toml` + thin Python API (`get_spec` / `list_specs`).

### `specs.yaml` schema (v1)

```yaml
registry_version: "0.1.0"          # version of the meta-package itself
specs:
  - id: login-spec                 # entry point name; CLI --spec value
    version: "1.0.0"               # exact pin only
    dist: login-spec               # PEP 503 distribution name
  - id: payment-spec
    version: "2.1.0"
    dist: payment-spec
```

Rules:

- `id` matches `^[a-z][a-z0-9-]*$` and equals the entry-point name  
- `version` is a PEP 440 exact version (no `>`, `>=`, `*`, `,`)  
- `dist` is on the allowlist in `policy.yaml`  
- No duplicate `id` or `dist`  

### `policy.yaml` (v1)

```yaml
allowed_dists:
  - login-spec
  - payment-spec
# Future: denied_transitive, max_specs, require_sdk_dep: true
```

### Sanitize algorithm (`scripts/sanitize.py`)

Exit **0** if OK, **1** + stderr reasons if not.

1. Parse `specs.yaml` / `policy.yaml` (fail on YAML errors).  
2. For each Spec entry:  
   - validate `id` / `version` / `dist` shape  
   - `dist in allowed_dists`  
   - version is exact (`packaging.version.Version` parse; reject strings with range operators)  
3. Fail if `len(specs) == 0` (empty registry not allowed in v1) or duplicates.  
4. Optional (v1.1): `pip download` / metadata inspect to assert Spec declares `xq-terminal-sdk` and entry point `xq_terminal.specs`:`id`.  

Do **not** write `pyproject.toml` in sanitize — only validate.

### Generate algorithm (`scripts/generate.py`)

1. Run sanitize (or assume CI already did).  
2. Emit `pyproject.toml`:

```toml
[project]
name = "xq-terminal-registry"
version = "0.1.0"   # from specs.yaml registry_version
description = "Sanitized meta-package of xq-terminal Specs"
requires-python = ">=3.11"
dependencies = [
  "login-spec==1.0.0",
  "payment-spec==2.1.0",
  "xq-terminal-sdk>=0.1,<0.2",
]

[project.scripts]
# none required

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"
```

3. Optionally emit `src/xq_terminal_registry/_catalog.py`:

```python
# AUTO-GENERATED by scripts/generate.py
CATALOG: dict[str, str] = {
    "login-spec": "login-spec==1.0.0",
    "payment-spec": "payment-spec==2.1.0",
}
```

### Runtime loader (`loader.py`)

```python
from __future__ import annotations
from importlib.metadata import entry_points
from xq_terminal_sdk import ENTRY_POINT_GROUP, RunnerSpec

def list_specs() -> list[str]:
    eps = entry_points(group=ENTRY_POINT_GROUP)
    return sorted(ep.name for ep in eps)

def get_spec(spec_id: str) -> RunnerSpec:
    eps = entry_points(group=ENTRY_POINT_GROUP)
    matches = [ep for ep in eps if ep.name == spec_id]
    if not matches:
        raise KeyError(
            f"unknown spec id {spec_id!r}; installed={list_specs()}"
        )
    loaded = matches[0].load()
    # entry point may be factory or instance
    spec = loaded() if callable(loaded) and not hasattr(loaded, "run") else loaded
    if not isinstance(spec, RunnerSpec):
        raise TypeError(f"{spec_id} entry point did not satisfy RunnerSpec")
    return spec
```
